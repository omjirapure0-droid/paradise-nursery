\# Paradise Nursery Shopping Application



\## Project Name

Paradise Nursery Shopping Application



\## Description

Paradise Nursery is an online plant shopping application where users can browse houseplants, view plant details and prices, add plants to a shopping cart, and manage their cart items.



\## Features

\- Browse houseplants by category

\- View plant names, images, and prices

\- Add plants to the shopping cart

\- Increase or decrease quantities

\- Remove plants from the cart

\- View the total cost of items

\- Continue shopping

\- Checkout functionality
